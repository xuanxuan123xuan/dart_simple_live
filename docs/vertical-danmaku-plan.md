# 竖屏直播弹幕（计划文档）

> 状态：**已登记，待实现**（大更新，不急）
> 归属：dev 分支 Roadmap

## 背景

竖屏直播（视频高度 > 宽度）在全屏时，现有的横向滚动弹幕（canvas_danmaku，从右往左）观感不自然。本计划为竖屏直播提供**竖屏弹幕模式**——左下角、从下往上、类聊天区的可滚动弹幕列表。

## 需求清单

| # | 需求 | 说明 |
|---|---|---|
| 1 | **左下角定位** | 弹幕列表锚定直播画面左下角（Stack 定位），宽度 ≤ 半屏 |
| 2 | **高度半屏 + 避让控制栏** | 高度 ≤ 画面一半；bottom 避开屏幕下方播放控制栏，不遮挡按钮 |
| 3 | **背景透明** | 列表无背景板/遮罩，只有弹幕文字（复用现有弹幕描边设置增强可读性） |
| 4 | **自动换行** | 横向限宽内 softWrap，长文本折 2~3 行（maxLines 上限防单条撑爆），高度随行数自适应 |
| 5 | **从底部追加、向上滚动** | 新弹幕自动追加到底部并滚动到最新（参考右侧聊天区交互） |
| 6 | **上滑回看历史** | 用户上滑可查看历史弹幕；滚动时暂停自动跟随，滑回底部恢复跟随 |
| 7 | **跟随视频方向** | 弹幕模式按 `isVertical`（视频方向）而非屏幕方向切换；**横屏看竖屏流也用竖屏弹幕** |
| 8 | **历史缓存水位** | 缓存最近 200 条防无限增长 |

## 实现方案

1. **app 新增 `VerticalDanmakuView`**（独立 Widget，不碰 canvas_danmaku，风险低可回退）
   - 位置：直播画面左下角（Stack 定位），宽度 ≤ 半屏
   - 高度：≤ 画面一半，bottom 避让控制栏（先固定估算高度，后续按实际 UI 微调）
   - 背景透明、文本换行、可滚动（自动跟随 + 上滑暂停）
   - 渲染复用现有弹幕设置（字号/颜色/emoji/描边）

2. **弹幕模式切换**
   - `live_room_page`：`isVertical` 时显示 `VerticalDanmakuView`、隐藏 canvas 弹幕；横屏流反之
   - 横屏看竖屏流：同样按 `isVertical` 判定

3. **弹幕分发**
   - `LiveRoomController.onMessage`：竖屏模式追加到 `VerticalDanmakuView`；横屏模式走 canvas 弹幕
   - 竖屏模式下 top/bottom 类型按普通弹幕处理

## 验证

- 逻辑单测：追加顺序 / 自动跟随 / 上滑暂停跟随 / 自动换行 / 半屏与底部避让计算
- `dart analyze`（app + core）
- 真机竖屏视觉与滑动体验需实机验证（本机无 Android 模拟器）

## 依赖

- `isVertical`（视频方向）判定已在 `player_controller.dart` 存在（基于播放器宽高流）
- 竖屏全屏方向策略：关联计划"全屏方向跟随视频方向"（`fullScreenForceLandscape` 默认关闭）
