# Simple Live 功能精简与信息架构方案

## 1. 目标

在不削弱 Simple Live 核心能力的前提下，减少功能入口堆叠和设置项混杂，让普通用户仍然能够“打开就看直播”，同时保留多开、同步和专业播放设置等进阶能力。

本方案遵循以下原则：

1. 直播浏览、搜索、关注、播放和弹幕属于核心能力，应保持直接可达。
2. 多开、数据同步等特色功能继续保留，但不与基础操作争夺主界面空间。
3. 专业参数和故障诊断不删除，统一收进高级设置或帮助与排障。
4. 删除明显偏离核心定位、使用门槛高且维护成本大的功能。
5. 后续优先改善播放稳定性和基础体验，谨慎增加统计、分析类功能。

## 2. 总体结论

### 2.1 删除

- 删除实时字幕功能。
- 删除字幕模型选择、模型推荐下载、字幕语言、样式、位置和锁定等相关设置。
- 删除 `sherpa_onnx` 及其桌面端原生依赖，避免无论用户是否使用字幕都携带相关运行库。
- 删除直播间“实时字幕”入口及 README 中的功能说明。

实时字幕与“简简单单看直播”的主线距离较远，使用前还需要用户自行准备模型，带来的安装体积、平台兼容和长期维护成本均高于实际收益。

### 2.2 保留但重新分层

- 多开同屏
- 数据同步
- 账号管理
- 观看记录
- 弹幕屏蔽和弹幕样式
- 自动选线、弱网恢复和延迟优化
- 网络诊断和日志
- mpv 专业配置

这些功能本身有价值，主要问题是入口层级和普通设置混在一起，不需要为了追求“精简”而直接删除。

### 2.3 暂停新增

- 弹幕热词统计
- 观看时长、平台分布和常看主播统计
- 跨平台响度归一化
- 面向普通用户的更多播放遥测面板

音量记忆、竖屏直播适配、全屏方向跟随视频等属于基础体验完善，可以继续实施。

## 3. 主导航

主导航维持四个页面：

1. 首页：推荐内容、平台切换、搜索入口。
2. 关注：已关注主播、标签、筛选、刷新和多开。
3. 分类：五个平台的分类与分区浏览。
4. 我的：账号、数据、设置和维护入口。

## 4. “我的”页面最终结构

正式版“我的”页面建议压缩为 7 个可点击入口：

1. **Simple Live 信息卡**
   - 版本信息
   - 免责声明
   - 开源主页
2. **观看记录**
3. **账号管理**
4. **数据与同步**
5. **清理缓存**
   - 作为一级入口保留
   - 直接显示当前缓存占用
6. **设置**
7. **帮助与排障**

当前分散在“我的”页面的外观设置、主页设置、直播间界面与快捷键、播放与网络、多开设置、弹幕设置、关注设置、定时关闭和其他设置，全部收进统一的“设置”入口。

“免责声明”和“开源主页”不再单独占用一级入口，合并到顶部 Simple Live 信息卡打开的关于页面。

## 5. 设置页面结构

“设置”页面分为以下栏目：

### 5.1 播放设置

- 默认清晰度和数据网络清晰度
- 画面尺寸
- 硬件解码
- 兼容模式
- HTTPS 播放链接
- 滑动调节音量和亮度
- 后台播放
- 小窗播放
- 网络波动时自动降低清晰度
- 网络波动提示
- 自动全屏
- 关播或播放失败后自动切换直播间
- 播放页显示项

### 5.2 弹幕设置

普通设置只直接展示：

- 弹幕默认开关
- 弹幕表情
- 字号
- 速度
- 不透明度
- 显示区域和行数
- 屏蔽管理

重复弹幕过滤、严格模式、过滤窗口、过滤步长、平台延迟补偿、安全边距、重点动态及其统计参数，统一收进“高级弹幕设置”。

### 5.3 关注与通知

- 自动更新关注状态
- 自动更新间隔
- 特别关注开播通知
- 关注页显示方式

更新线程数和每页数量属于专业参数，应移入高级设置，并优先使用自动值。

### 5.4 多开设置

- 聊天区显示方式
- 单路声音或多路混音
- 自动调节多开画质
- 低内存自动降级
- 布局间距
- 关闭全部独立多开窗口

### 5.5 外观与主页

- 跟随系统、浅色和深色主题
- 动态取色和主题色
- 首页栏目排序
- 平台排序

### 5.6 定时关闭

- 启用定时关闭
- 自动关闭时间

### 5.7 高级设置

- 直播间标签顺序
- 全屏长按快捷入口及排序（关注、历史、同类推荐、贡献榜及默认关闭的网络诊断）
- 桌面快捷键
- 关注更新线程数和分页数量
- 弹幕高级过滤参数
- mpv 性能档位和延迟档位
- 视频、音频输出驱动
- 硬件解码器
- 导入 `mpv.conf`
- 自定义 mpv options
- 同步服务器和代理地址

## 6. 直播间功能安排

### 6.1 常驻控制

- 播放和暂停
- 静音和音量
- 弹幕开关
- 清晰度
- 播放线路
- 全屏
- 更多功能

### 6.2 “更多功能”菜单

- 播放调整（清晰度、线路、画面尺寸）
- 截图
- 小窗播放
- 定时关闭
- 分享与链接（直播链接、播放直链、官方 APP）
- 网络诊断与播放信息

直播间“设置”标签只直接保留文字大小、气泡样式和重复弹幕过滤三个现场常调项。关键词屏蔽、完整弹幕设置和完整播放设置作为二级入口；“网络诊断与播放信息”也放在这里，因为诊断必须依赖当前直播间和当前线路。动态统计跨度、过滤窗口、过滤步长等专业参数不在直播间直接展示。

“网络诊断与播放信息”复用快捷入口容器内的二级页面，直接展示链路健康、当前端点和播放器信息；从快捷入口、直播间设置或“更多功能”进入时都不再叠加新的诊断弹窗。

### 6.3 获取播放直链

“获取播放直链”必须依附当前直播间、清晰度和播放线路，不再作为“我的”页面中的独立工具。

在“直播间界面与快捷键”中增加开关：

> 显示“复制播放直链”

- 默认关闭。
- 开启后，直播间“更多功能”菜单显示“复制播放直链”。
- 复制当前实际选中的清晰度和线路对应的播放地址。
- 不再保留“我的 → 链接解析 → 获取直链”的操作路径。

### 6.4 直播链接跳转

不再为“直播间跳转”保留独立一级页面。用户向搜索框粘贴支持平台的直播链接时：

1. 自动识别链接所属平台。
2. 解析直播间标识。
3. 直接打开对应直播间。
4. 无法识别时再按普通搜索词处理或显示明确错误。

## 7. 关注功能安排

以下功能继续保留：

- 本地关注和取消关注
- 特别关注
- 标签创建、改名、排序和删除
- 按平台、直播状态和标签筛选
- 搜索已关注主播
- 只显示正在直播
- 当前页刷新和全部刷新
- 从关注列表批量选择多开
- 开播通知

关注列表自身的文件、文本导入导出入口不再铺开显示，统一转移到“数据与同步”。

## 8. 多开同屏

多开属于有辨识度的特色功能，应继续保留：

- 2～4 路同屏
- 均分和主次布局
- 设置主画面
- 双击聚焦和退出聚焦
- 转到单直播间
- 从关注和历史添加直播间
- 单路暂停、静音、刷新、清晰度和线路选择
- 全部暂停、全部静音和全部刷新
- 单路声音与多路混音
- 低内存降级
- 自动调节多开画质
- 桌面端独立窗口

多开的性能治理应尽量自动完成，避免继续增加普通用户需要理解的参数。

## 9. 数据与同步

将分散的数据迁移功能统一收进“数据与同步”：

1. **局域网扫码迁移**：适合同一网络内的新旧设备。
2. **配置包导入导出**：适合跨平台离线迁移和手工备份。
3. **WebDAV**：适合长期云端备份。
4. **临时同步房间**：适合设备间临时传输。
5. **高级连接设置**：自建服务地址和代理地址。

同步范围统一说明为：

- 设置
- 关注
- 标签
- 观看历史
- 弹幕关键词和用户屏蔽数据

各业务页面可以提供“管理备份”跳转，但不再分别实现多套文件和文本导入导出界面。

## 10. 帮助与排障

该页面承接不应暴露在普通设置中的维护能力：

- 常见播放问题说明
- 网络诊断
- 当前播放信息
- 日志开关
- 日志查看、分享和清空
- 配置重置
- 构建版本和平台信息

“清理缓存”因使用直观且频率较高，仍留在“我的”一级页面，不并入帮助与排障。

## 11. 功能分层规则

以后新增功能前按以下标准判断：

### 核心功能

满足“找直播、看直播、管理关注”之一，可以进入主流程。

### 增强功能

能明显改善观看体验，但不是所有人都使用，应放二级页面或“更多功能”。

### 高级功能

需要用户理解播放器、网络、同步协议或平台限制，应默认隐藏在高级设置。

### 排障功能

主要用于定位问题，不作为日常功能宣传，统一放入帮助与排障。

### 不建议加入

与直播观看关系较弱、需要大量新依赖、带来持续兼容成本，或只是展示更多统计数字的功能，原则上不加入。

## 12. 实施顺序

### 第一阶段：直接减负

1. 删除实时字幕及 `sherpa_onnx` 依赖。
2. 删除字幕相关页面、入口、设置和文档。
3. 将“我的”页面收拢为 7 个入口。
4. 将免责声明和开源主页并入关于页面。

### 第二阶段：重新组织

1. 建立统一设置首页。
2. 建立高级设置页面。
3. 建立帮助与排障页面。
4. 合并数据迁移和同步入口。
5. 将直播直链功能迁回直播间，并增加显示开关。

### 第三阶段：降低操作复杂度

1. 搜索框支持粘贴直播链接直接跳转。
2. 自动处理多开画质、播放器延迟和关注刷新参数。
3. 精简普通弹幕设置，只保留高频选项。
4. 对低频功能采用默认关闭和按需显示。

## 13. 验收标准

- 正式版不再包含实时字幕入口和相关原生运行库。
- “我的”页面只有 7 个可点击入口。
- 清理缓存继续作为一级入口并显示占用空间。
- 直播直链只能从当前直播间获取，且默认不显示入口。
- 普通设置中不直接展示 mpv、线程数、过滤窗口等专业参数。
- 原有多开、账号、同步、历史、弹幕屏蔽和播放增强功能均可继续访问。
- 新用户无需进入高级设置即可完成搜索、关注和观看直播的完整流程。
